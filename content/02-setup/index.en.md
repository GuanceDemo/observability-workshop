## Environment Setup

This chapter completes the foundational environment configuration from scratch to observable:

1. Declare EKS and DataWay parameters, and install DataKit using Helm.
2. Create a Web RUM application in TrueWatch and record the Application ID and Workspace ID.
3. Deploy the microservice mall to EKS using public images and obtain the public access URL.

Parameters that require user input are AWS Region, EKS cluster name, DataWay URL, RUM Application ID, and TrueWatch Workspace ID. `project=mall-demo`, image tag `latest`, Namespace, and Demo internal passwords are fixed or auto-generated by the tutorial.
