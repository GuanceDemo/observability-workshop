## Environment Setup

This chapter completes the foundational environment configuration from scratch to observable:

1. Declare EKS and DataWay parameters, and install DataKit using Helm.
2. Create a Web RUM application in TrueWatch and record the Application ID and Workspace ID.
3. Deploy the microservice mall to EKS using public images and obtain the public access URL.

Parameters that require user input are DataWay URL, RUM Application ID, and TrueWatch Workspace ID. `project=mall-demo`, image tag `2.3.0`, Namespace, and Demo internal passwords are fixed or auto-generated by the tutorial.

The chapters retain the manual path for teaching. After preparing the EKS cluster and TrueWatch RUM application, the equivalent fast path is:

```shell
export DEMO_VERSION="2.3.0"
git clone --branch "v${DEMO_VERSION}" --depth 1 \
  https://github.com/GuanceDemo/observability-demo.git
cd observability-demo
scripts/workshop.sh install
```
